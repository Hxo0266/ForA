# 0_inbox — CHM1001 唯一入口

> 本文件是**占位文件**，不是说明书的替代品。删掉它会让本目录在打包/备份时静默消失（见 `_System/ERROR_LOG.md` **AIE-025**）。

## 这个目录是什么

**所有待分类材料的第一落点。** 拿到课程材料不用想它属于哪一类，直接丢进来，然后说一句：

> **「处理一下 inbox」**

分类器会先做**开工检查**、再出**分类计划**、**等你点头之后**才移动文件。

## 材料会被分到哪里

| 命中什么 | 去哪 |
|:--|:--|
| 课件词 / 讲次编号（`L03`、`Ch2`、`Week5`）/ `.ppt` `.pptx` | `2_Textbook&Lecture_PPT/` |
| 大纲、评分标准、课表、学术诚信 | `1_Syllabus/` |
| 作业词（`homework` / `作业` / `实验报告` / `习题`） | `4_Assignment/` |
| 小测词（`quiz` / `小测` / `随堂演练`） | `5_Quiz/` |
| 期中标识 | `6_Midterm Examination/` |
| 期末标识 | `7_Final Examination/` |
| **错题词**（`错题` / `易错题` / `correction` / `wrong question`） | `8_Correction_Notebook/` |
| 兜底 | `10_Others/` |

分类规则以 `_System/taxonomy.json` 为**唯一事实源**，改规则改那个文件即可。

## 两条硬规矩

1. **绝不删除任何文件。** 每次移动都留可回滚清单（`_System/logs/moved_*.json`）。
2. **定时自动化绝不碰这个目录。** 每周六凌晨那轮只做「课件 → 笔记」，不移动、不归档——归档必须由你本人确认。

## 这个目录应该长期是空的

处理完一轮，它就空了。**里面长期躺着文件 = 流程没跑**（`health_check.py` 的 **O1 / AIE-002** 会报出来）。
