# 10_Others — CHM1001 兜底目录

> 本文件是**占位文件**。删掉它会让本目录在打包/备份时静默消失（见 `_System/ERROR_LOG.md` **AIE-025**）。

## 这个目录装什么

**以上分类都不中的一切。** 它是兜底，不是垃圾桶——每进来一份材料，都带着「为什么进这里」的记录。

## 进来通常有三种成因

| 成因 | 表现 | 你该做什么 |
|:--|:--|:--|
| **泛考试词但分不清场次** | 如 `Exam 题型总结.pdf`——只命中 `exam`/`test`/`试卷`，没有期中期末标识 | 看一眼，手动说到底属于哪一场 |
| **`essence` 类词但扩展名不对** | 如 `笔记汇总.pdf`——`3_Essence/` 只收与课件同名的 `.md` | 若是课件对应的笔记，改名为与课件同名 |
| **真正的杂项** | 与课程弱相关的文件 | 不用管，或者自己移走 |

前两种都会在分类报告里被标 **`标记需确认` / `标记需复核`**，不会被静默丢进来。

## 为什么单独讲这件事

因为**兜底目录最容易变成垃圾桶**，而垃圾桶里的东西没人再看第二遍。

所以本目录的每一份材料在报告里都带成因说明；`health_check.py` 的 **O6** 还会主动复查
「这里有没有其实是漏判的文件」——把误入兜底的东西捞回正确位置。

## 这个目录应该长期接近空

如果它开始堆积，说明分类规则该调了——改 `_System/taxonomy.json`。
