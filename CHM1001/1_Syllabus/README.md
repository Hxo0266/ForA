# 1_Syllabus — CHM1001 教学大纲与非教学内容

> 本文件是**占位文件**。删掉它会让本目录在打包/备份时静默消失（见 `_System/ERROR_LOG.md` **AIE-025**）。

## 这个目录装什么

**全部「非教学内容」的课程文件**——也就是那些规定「这门课怎么上、怎么算分」的文件，而不是「课本身」。

命中以下关键词的材料会从 `0_inbox/` 自动归到这里：

| 英文 | 中文 |
|:--|:--|
| `syllabus` / `course outline` / `course description` / `course info` | 教学大纲 / 课程大纲 / 课程纲要 / 课程介绍 / 课程简介 |
| `grading policy` / `grading scheme` / `rubric` / `assessment` | 评分标准 / 考核方式 / 评分细则 |
| `schedule` / `timetable` / `calendar` | 课程安排 / 教学安排 / 课表 |
| `academic integrity` / `honor code` / `attendance` | 学术诚信 / 出勤 |

**注意**：必须同时**没有**讲次编号（`L03`、`Ch2`）、**也没有**课件词，才会归到这里——避免把「Lecture 3 的评分说明」误当大纲。

## 与课程纲要的关系

本目录的原始文件是**素材**；根目录的 `Outline of CHM1001.md` 是**合并产物**（把这里的大纲与 `2_Textbook&Lecture_PPT/` 的教材目录合并）。

想生成/更新纲要，说一句：

> **「生成 Outline of CHM1001」**

## 顺带一提

`Outline of CHM1001.md` 写好后，「对话框里直接问一道题 → 自动识别属于哪门课 → 归入错题本」这条路会**更准**——它优先读这个文件。
