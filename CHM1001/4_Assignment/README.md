# 4_Assignment — CHM1001 课程作业

> 本文件是**占位文件**。删掉它会让本目录在打包/备份时静默消失（见 `_System/ERROR_LOG.md` **AIE-025**）。

## 这个目录装什么

课程布置的**作业**（homework / assignment / lab report / project）——
凡是「要你写、要你交」的东西归这里，「考你」的东西归 `5_Quiz/` 和 `6/7_* Examination/`。

命中以下关键词、且**没有**讲次编号与课件词的材料会从 `0_inbox/` 归到这里：

`homework` · `assignment` · `hw` · `lab` · `lab report` · `report` · `project` ·
**作业** · **大作业** · **实验报告** · **习题** · **练习册**

## ★ 作业收进来时会自动发生一件事

**（ForA 1.1.0 起的固定行为）** 一旦作业被归入本目录，助手会**自动**：

1. 读这份作业；
2. **逐题**给出答案与简要解析；
3. 生成配套文档 **`<作业名主干>-答案.md`**，放在**同一个 `4_Assignment/` 目录**里。

配套存放，不另立目录——答案与题目分开就没人对得上了。

> 这是**模型任务**，在对话里完成；脚本只负责移动文件。
> 定时自动化**不做**这件事（无人在场、且写答案需要判断）。

## 与错题本的区别

| | 去哪 | 判据 |
|:--|:--|:--|
| 一份**要交的作业** | 本目录 `4_Assignment/` | 命中作业词 |
| **一道做错的题** | `8_Correction_Notebook/` | 命中错题词，或由助手判断「这是一道单独的题」 |

错题词**优先于**作业词——两者都命中时归错题本。
