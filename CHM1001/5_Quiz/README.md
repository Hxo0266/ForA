# 5_Quiz — CHM1001 小测与随堂练习

> 本文件是**占位文件**。删掉它会让本目录在打包/备份时静默消失（见 `_System/ERROR_LOG.md` **AIE-025**）。

## 这个目录装什么

**课堂内的、小规模的**测验与练习——不算分期中期末的那些。

命中以下关键词、且**没有**讲次编号与课件词的材料会从 `0_inbox/` 归到这里：

`quiz` · `quizzes` · `pop quiz` · `mini test` ·
**小测** · **小测验** · **随堂** · **随堂演练** · **随堂测验** · **随堂练习** · **课堂测验** · **课堂练习**

## 分类优先级（为什么它排在作业前面）

分类器按这个顺序定级：

```
期末 > 期中 > 错题 > 小测 > 作业 > 泛考试词 > 大纲
```

所以「Quiz 3」这种既像小测又像讲次文件的，小测词赢。
但若文件名带讲次编号（`L03`、`Ch2`）或课件词（`Lecture`、`PPT`），会被判成**课件**归 `2_Textbook&Lecture_PPT/`——因为那更可能是随堂发的讲义。

## 一个容易搞混的地方

| 特征 | 去哪 |
|:--|:--|
| 「Quiz 3」「随堂测验」——**题目本身** | 本目录 |
| 「Quiz 3 答案」「Quiz 3 解析」 | **也归本目录**（`answer` 是修饰词，不改变归属） |
| 「Quiz 3」但内容是**一页纸的课件** | `2_Textbook&Lecture_PPT/` |

拿不准的会被标上**需确认**，等你复核，不会猜着归。
