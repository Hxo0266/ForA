## 期中 / 期末怎么分

分类器按**从具体到宽泛**的顺序判断，所以入口对结果影响很大：

| 文件名的样子 | 去哪 | 为什么 |
|:--|:--|:--|
| `Midterm 2026.pdf` | **本目录** | 命中 `midterm`，具体标识优先 |
| `期中考试真题.pdf` | **本目录** | 同上 |
| `Final Exam 2025.pdf` | `7_Final Examination/` | 命中 `final` |
| `Exam 题型总结.pdf` | `10_Others/` + **标记需确认** | 只命中泛考试词，无法判断哪一场 |

最后一行是**故意**的：宁可疑问，不猜着归错。
