# 7_Final Examination — CHM1001 期末试卷与答案

> 本文件是**占位文件**。删掉它会让本目录在打包/备份时静默消失（见 `_System/ERROR_LOG.md` **AIE-025**）。

## 这个目录装什么

**期末**阶段的试卷、真题、答案与解析。

会归到这里的标识：`final` · `finals` ·
**期末考试** · **期末考** · **期末** · **末考** · **大一统考**

## 为什么它排在分类优先级第一位

分类器定级顺序：

```
期末 > 期中 > 错题 > 小测 > 作业 > 泛考试词 > 大纲
```

`final` 是最具体的考试标识，出现它就不用再看别的词了。这条顺序是**刻意**的：
`Final Exam 答案.pdf` 里既有 `final` 也有 `answer`，若按 `answer` 走就会出错。

## 一个真实边界情况

R 语言里 `final` 是保留字（`final` 类、`final` 方法），化学课件的文件名里也可能出现
`Final Product`（最终产物）这类表述。

**所以**：若文件名同时带**讲次编号**或**课件词**，会被判成**课件**归
`2_Textbook&Lecture_PPT/`，而不是期末卷。这条边界在 `AIE-024` 里有说明。

## 内容兜底

文件名看不出来时，分类器读正文首段，出现 `Final Examination` / `期末考试` 特征就归这里，并附「**需复核**」标记。
