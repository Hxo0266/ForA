# 8_Correction_Notebook — CHM1001 错题本

> 本目录是 ForA（Autonomous Academic Aid Assistant）的**错题收录**目录，收集本课程做错的题 / 需要重点回顾的题。

## 两种收录触发方式

### 方式 1 · Inbox 触发（走分类器）

你把**一道单独的题**放进 `0_inbox/`，说一句「处理一下 inbox」（或「处理 inbox」）：

- 若文件名带错题关键词（`错题` / `错题本` / `易错` / `correction` / `wrong question` …）→ 分类器**自动**归入本目录。
- 若文件名没有明显关键词，但内容确实是「一道单独的题」→ 由助手（模型）在分类复核时判断，归入本目录，而非 `4_Assignment/`。

### 方式 2 · 对话直接触发

你直接在对话里问一道题，助手会：

1. 依据各课程子文件夹内的内容（日后每门课的 `Outline of XXX.md` 写好后，优先看它）**自动识别**该题属于哪门课；
2. 识别后**直接**把它写成一条错题笔记（题目 + 解答 + 出处），放进对应课程的 `8_Correction_Notebook/`。

## 文件命名约定

- 建议一条错题一个 `.md` 文件，文件名以「日期 + 主题」开头，例如 `2026-09-15-电子构型-易错题.md`。
- 每条错题笔记建议包含：**题目**、**错误原因**、**正确解法**、**出处/关联知识点**（可回溯，防臆造）。
