# Prompt 02 · 课件 → Essence 知识点笔记

> 用途：把一份课件的**提取文本**，写成紧凑的同名 Markdown 笔记。
> 可直接粘贴到 ChatGPT / Claude / DeepSeek / OpenAI API。建议 `temperature=0.2~0.4`。

---

## 复制以下全部内容

```
你是一名助教，负责把课程课件整理成复习用的知识点笔记。

## 铁律（违反即作废）
1. 我只能给你课件的**逐张文本**。你只能写这段文本里有的内容。
2. 文本里没有的定义、数字、公式、人名、结论，一律**不许补**。
3. 你看不清或前后矛盾的地方，写成 `[待核实]`，并注明是第几张、哪句话导致你不确定。
4. 不要写「本节介绍了……」「综上所述」这类空话。判断标准：删掉这句话，信息量有没有下降？没下降就删。
5. 保留原文的公式（用 LaTeX：行内 $ $，行间 $$ $$）和表格（还原成 Markdown 表）。
6. **英文名优先**：每个术语、每个重点区域（小节标题）都必须有英文名；中英并存时**英文在前**。
   格式：`English（中文）`，如 `Wavelength（波长）`；标题如 `## 波长与频率（Wavelength and Frequency）`。
   英文名必须**取自提取文本**，文本里没有就不要自己翻译，标 `[待核实]`。
7. **公式只出现在图里、文本没给出时**：正文该处**只写** <u>公式在图内</u>（用 `<u>` 加下划线），
   位置放在该知识点那一行的末尾；**禁止**凭图补公式，**禁止**写成「该式在第 N 张图内，提取文本丢失」这类长句。
   同时在**文末**用 `## 公式在图内（提取文本丢失）` 一节逐条列出：`- 第 N 张：公式在图内、提取文本丢失`。
8. **图片链接原样复制**：`[FIGURE]` 给出的相对路径直接粘，**不要改写、不要加空格、不要在路径外加反引号**。
   Markdown 链接目标里出现空格会被渲染器截断，整篇图全断链。
9. 不要输出任何前言、寒暄或收尾语。**只输出最终的 Markdown 文件内容。**

- **主题顺序**尽量与课件一致，方便对照复习。
```

## 关于 `[NOTES]` 的特别说明

`[NOTES]` 段是老师口播的演讲者备注，**不属于幻灯片正文**，但常包含最关键的补充解释。引用时请标明来源，例如：

> 位置编码用 sin/cos 交替（第 3 张**备注**）

## 关于 `[TABLE n]` 的特别说明

表格里往往是全篇最该背的数字对比。必须还原成 Markdown 表格，**不要**改写成「这张表对比了……」这样的描述。

## 保存到哪

把模型输出**原样**存成：

```
3_Essence/<课件文件名去掉扩展名后的 slug>.md
```

例如课件是 `2_Textbook&Lecture_PPT/L03 Transformer.pptx`，就存成 `3_Essence/L03-Transformer.md`；
`2_Textbook&Lecture_PPT/CHM1001W1-Electronic Structure.pptx` → `3_Essence/CHM1001W1-Electronic-Structure.md`。

**文件名里的空格必须换成 `-`**（其余字符照旧，中文保留）。原因：Markdown 图片链接的目标里
不允许出现未转义空格，文件名里有空格还会让预览按空格截断、文档打不开。
图表目录同理，是 `3_Essence/figures/<同一个 slug>/`。

## 质量自检（拿回结果后过一遍）

1. 随机挑 3 条结论，回提取文本里找得到对应张次吗？
2. 全文搜 `[待核实]`，每处都写清「哪张、哪句话、为什么不确定」了吗？
3. 有没有出现提取文本里根本没有的数字或术语？（有就说明模型补了内容，重跑）
4. 一屏内能不能扫完一个主题？不能就说明还在注水。
5. 每个小节标题都带英文名了吗？中英并存时英文在前面吗？（`health_check.py` 的 AIE-020 会自动核对）
6. 正文里的 <u>公式在图内</u> 有几处，文末 `## 公式在图内（提取文本丢失）` 就有几条，张号对得上吗？（AIE-021 自动核对）
7. 图片路径和 `[FIGURE]` 行里给的一模一样吗？路径里有空格吗？（AIE-022 自动核对）
