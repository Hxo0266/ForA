- 笔记名 = 课件名过 **`slug()`**（空白 → `-`，其余不安全字符 → `-`，**中文保留**），图表目录用同一个 slug。
- 一份课件 ↔ 一份笔记，不做合并、不做拆分。配对统计**按 slug 比**，所以带空格的课件不会被误报成「待提炼」。
- 索引文件固定叫 `3_Essence/00_Index.md`，它**不**参与配对统计。`2_Textbook&Lecture_PPT/` 里的**原文件不改名**。

> ⚠️ **为什么必须去空格**：Markdown 链接目标 `![alt](dest)` 里**不允许出现未转义的空格**——
> 渲染器会在第一个空格处截断，把后半截当成 title，于是**整篇的图全部不显示**；文件名里的空格
> 还会让预览/卡片按空格截断，文档直接打不开。中文留在路径里没问题（UTF-8 路径是安全的），
> **空格和括号才是杀手**。

## 四、八个容易踩的坑

1. **凭印象补内容**。提取文本里没有的定义、数字、人名，一律不写。想补就标 `[待核实]` 并说明依据。
2. **把备注（notes）当正文**。演讲者备注是老师口播内容，价值高但**不是幻灯片正文**——引用时标明「备注」。
3. **忽略表格**。提取产物里 `[TABLE n]` 段常含最关键的数字对比，必须还原成 Markdown 表。
4. **公式降级成文字**。凡是原文给公式的，保留 LaTeX，不要改写成「用 Q 乘 K 的转置」。
5. **丢讲次顺序**。主题顺序尽量与课件一致，方便对照复习。
6. **覆盖用户的批注版**。若 `3_Essence/<slug>.md` 已被用户手改过，先问，或另存 `<slug>_v2.md`。
7. **⭐ 小节标题只有中文**。术语和重点区域（小节标题）都必须带英文名，**中英并存时英文在前**：
   `## 波长与频率（Wavelength and Frequency）`、`Wavelength（波长）`。英文名一律取自提取文本，
   **不要自己翻译**——文本里没有英文名的，标 `[待核实]`。
8. **⭐ 公式在图内时自己补公式**。文本里没有、只在图里的公式，正文该处**只写** <u>公式在图内</u>
   （下划线），并在**文末** `## 公式在图内（提取文本丢失）` 逐条列 `- 第 N 张：公式在图内、提取文本丢失`。
   **禁止**凭图补公式，也**禁止**在正文写「该式在第 N 张图内，提取文本丢失」之类的长句。

## 五、图文混排规则（本次流程优化的重点）

**一句话：`[FIGURE]` 标了几张，笔记里就要有几张，且必须贴在对应知识点正下方。**

| ✅ 该做 | ❌ 不该做 |
|:--|:--|
| 在该张知识点所在小节的**末尾**插图 | 把所有图集中堆到文档末尾 |
| 图题写「第 N 张：<这张图说明了什么>」 | 只写「（见图）」「见第 7 张」却不真的插图 |
| 图本身是主体时，另用要点写出图中的关键关系 | 用图代替全部文字，纯文字阅读时信息全丢 |
| 相对路径**原样照抄** `[FIGURE]` 给出的那一串 | 自己编路径、改大小写、加空格、在路径外加反引号 |

兜底机制：某张图**没被引用** → `health_check.py` 的 **AIE-017** 报 `⚠️ WARN`；引用的路径**不存在或语法非法** → 报 `❌ FAIL`。

> ⚠️ **链接语法必须合法**：路径里出现空格会让渲染器在空格处截断，**图全断**；括号、`#`、`?` 同理。
> 生成侧已经用 `slug()` 保证不出现这些字符（AIE-022），所以笔记里**照抄即可**，不要自己加工。
> 万一遇到带空格的路径，正确写法是尖括号包裹：`](<figures/a b/slide-01.png>)` —— 但更该做的是
> 让课件名先过 `slug()`。

**图从哪来**：`3_Essence/figures/<slug>/slide-NN.png`，由 `extract_slides.py` **整页渲染**得到（默认 150 dpi）。**不要自己生成、美化、重画或裁切**。

**标题也带英文**：结构性的小节（关键术语 / 易错点待核实 / 出处索引 / 公式在图内）由模板固定，不必再加英文；其余小节标题一律中英并列。

## 六、写完之后的自检

1. **覆盖率**：跑 `run_pipeline.py --skip-triage`，看「待提炼」是否为空。
2. **可溯源**：随机挑 3 条结论，回 `_System/extracted/<stem>.slides.txt` 找得到对应张次。
3. **无臆造**：全文搜 `[待核实]`，确认每处都写清了「哪张、哪句话、为什么不确定」。
4. **图文配对**：跑 `health_check.py --phase close`，确认 **AIE-017** 是 `✅ PASS`（无断图、也无未被引用的图）。
5. **英文名**：确认 **AIE-020** 是 `✅ PASS`（每个小节标题、每条术语都带英文名）。注意这条检查是**代理指标**，
   `vs`、`ml` 之类的残留 token 也会被判成「有英文」，仍需人工过目。
6. **公式在图内**：确认 **AIE-021** 是 `✅ PASS`（正文标注数 == 文末清单条数，且该节在全文最末）。
7. **链接安全**：确认 **AIE-022** 是 `✅ PASS`（无空格路径、无绝对路径、无死链，且 slug 实现无漂移）。
